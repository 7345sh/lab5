## Средний уровень сложности

Добавлено 3 файла **.py** с решением заданий индивидуального варианта.

**hello_button.py** — задание 1, окно с кнопкой "Привет". Создано главное окно приложения, размещены кнопка и текстовая метка. При нажатии на кнопку срабатывает обработчик события, который изменяет текст метки на приветствие.

**calculator.py** — задание 3, простейший калькулятор. Реализован графический интерфейс с двумя полями для ввода чисел, кнопками арифметических операций и меткой для вывода результата. Выполнение операций происходит по нажатию на соответствующую кнопку, обрабатываются ошибки ввода и деление на ноль.

**notebook.py** — задание 5, программа со вкладками. Создан виджет Notebook с тремя вкладками. Каждая вкладка представляет собой отдельный фрейм с некоторой информацией.

## Повышенный уровень сложности

Добавлено 2 файла **.py** с решением заданий повышенной сложности.

**notes.py** — задание 1, программа "Заметки". Создано окно с многострочным текстовым полем для ввода заметок, полем для указания имени файла и кнопкой сохранения. Реализована логика сохранения текста в файл, автоматическое добавление расширения .txt при необходимости, а также обработка ошибок файловой системы.

**plot.py** — задание 4, график matplotlib внутри Tkinter. Реализовано окно, в которое встроен график функции y = x^2 с помощью холста FigureCanvasTkAgg. На графике настроены подписи осей, заголовок, линии осей, сетка и легенда.

Для работы кода, помимо стандартных библиотек, требуется установка библиотеки matplotlib. Установка осуществляется командой pip install -r requirements.txt.
